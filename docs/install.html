Install f1-pitwall

Pick the computer that runs pitwall. Each path takes about 10 minutes. The game always runs on the Windows game PC.

1Game PC onlyPitwall runs on the Windows PC that runs F1 26. 2Mac serverA Mac runs pitwall. The game PC sends it telemetry. 3Linux serverA Linux box runs pitwall. The game PC sends it telemetry.

Path 1Game PC only (Windows)

Everything runs on the game PC. The engineer speaks through the PC's audio, so you hear it in your headset.

  1. Run the installer

    Press Start, type PowerShell and open it. Paste this line and press Enter.

    irm https://raw.githubusercontent.com/artsworks/f1-pitwall/main/install/install.ps1 | iex

    The installer adds uv and Git, downloads pitwall to %USERPROFILE%\f1-pitwall and makes the shortcuts. If it asks you to reopen PowerShell, do that and paste the line again.

    Where does F1 26 run? 1) On this PC 2) On another PC or console on this network Choice [1]: 1 Download the natural voice (about 60 MB)? [Y/n]: Y

  2. Set the game's telemetry

    In F1 26, open Settings, Telemetry Settings. Set the values shown. Restart the game after you change them.

    Telemetry Settings
    Settings > Telemetry Settings
    UDP TelemetryOn
    UDP Broadcast ModeOff
    UDP IP Address127.0.0.1
    UDP Port20777
    UDP Send Rate30 Hz
    UDP Format2026

  3. Start pitwall

    Double-click the Pitwall shortcut on the desktop or in the Start menu. You hear "Pit wall online."

    Keep the window open while you drive. Close it to stop pitwall.

    pitwall start dashboard http://localhost:8000 LAN http://192.168.1.20:8000 ┌──────────────────────────────┐ │ PIN 4821 (LAN devices only) │ └──────────────────────────────┘

  4. Open the dashboard

    On the second monitor, open http://localhost:8000 in a browser. It goes LIVE when you are on track.

    /radio shows a compact call log. This PC needs no PIN.

    localhost:8000
    LIVE · LAP 12 / 57RADIO: Box this lap, box this lap.

  5. If the dashboard says STALE

    Drive onto the track, then run the check in PowerShell from the pitwall folder:

    cd $HOME\f1-pitwall; uv run pitwall doctor --seconds 30

    "0 datagrams" means the game sends nothing. Check the settings in step 2. Then run the two netsh firewall lines that doctor prints, in PowerShell opened with Run as administrator.

Game on another PC or console?

Pitwall can run on this Windows PC while the game runs on another device. Choose 2 in the installer. Then change three things:

  1. Set UDP IP Address in the game to this PC's LAN address. The installer prints it, and pitwall prints it at start as LAN.
  2. Allow pitwall through the Windows firewall. Open PowerShell with Run as administrator and run both lines:
    netsh advfirewall firewall add rule name="pitwall udp" dir=in action=allow protocol=UDP localport=20777 netsh advfirewall firewall add rule name="pitwall tcp" dir=in action=allow protocol=TCP localport=8000
  3. On other devices, open http://<LAN address>:8000 and type the 4-digit PIN that pitwall prints at start. The PIN changes every start.
Update later: close pitwall, then double-click Pitwall Update. It prints the old and new version.

Path 2Mac server, Windows game PC

The Mac runs pitwall. The game PC sends telemetry to the Mac and shows the dashboard on its second monitor.

Where the voice plays. The Mac plays no engineer audio. The voice plays in the browser tab that shows the dashboard. Open the dashboard on the game PC to hear it in your headset.

  1. Run the installer on the Mac

    Open Terminal (Applications, Utilities). Paste this line and press Enter.

    curl -LsSf https://raw.githubusercontent.com/artsworks/f1-pitwall/main/install/install.sh | sh

    If macOS asks to install the Command Line Tools, click Install. Then paste the line again. Answer 1 to open the dashboard on the game PC.

    Where will you open the dashboard? 1) On the Windows game PC (second monitor) 2) On this computer Choice [1]: 1 ... Game PC UDP IP Address: 192.168.1.30

  2. Set the game's telemetry on the game PC

    Use the Mac's LAN address as the UDP IP, not 127.0.0.1. The installer prints it, and pitwall prints it at start as LAN.

    Telemetry Settings
    Settings > Telemetry Settings
    UDP TelemetryOn
    UDP Broadcast ModeOff
    UDP IP Address192.168.1.30 (the Mac)
    UDP Port20777
    UDP Send Rate30 Hz
    UDP Format2026

  3. Start pitwall on the Mac

    Double-click Pitwall.command on the Mac desktop. Note the 4-digit PIN in the window.

    If macOS asks whether python may accept incoming network connections, click Allow. Without that, the game PC cannot reach the Mac.

    pitwall start dashboard http://localhost:8000 LAN http://192.168.1.30:8000 ┌──────────────────────────────┐ │ PIN 4821 (LAN devices only) │ └──────────────────────────────┘

  4. Open the dashboard on the game PC

    On the game PC's second monitor, open the address below with the Mac's LAN address. Type the PIN, then click ENABLE SOUND.

    http://192.168.1.30:8000/?sound=1

    The PIN changes each time pitwall starts. Keep the tab open, because the voice plays from it.

    192.168.1.30:8000/?sound=1
    ENTER PIN
    4821
    ENABLE SOUND

  5. If the dashboard says STALE

    Drive onto the track, then run the check in Terminal on the Mac:

    cd ~/f1-pitwall && uv run pitwall doctor --seconds 30

    "0 datagrams" means nothing reaches the Mac. Check the UDP IP in step 2. Then open System Settings, Network, Firewall and allow incoming connections for python.

Update later: close pitwall, then double-click Pitwall Update.command on the Mac desktop.

Path 3Linux server, Windows game PC

The Linux box runs pitwall. The game PC sends telemetry to it and shows the dashboard on its second monitor.

Where the voice plays. The Linux box plays no engineer audio. The voice plays in the browser tab that shows the dashboard. Open the dashboard on the game PC to hear it in your headset.

  1. Run the installer on the Linux box

    Open a terminal. Paste this line and press Enter.

    curl -LsSf https://raw.githubusercontent.com/artsworks/f1-pitwall/main/install/install.sh | sh

    If Git is missing, the installer asks for your password to install it. Answer 1 to open the dashboard on the game PC.

    Where will you open the dashboard? 1) On the Windows game PC (second monitor) 2) On this computer Choice [1]: 1 ... Game PC UDP IP Address: 192.168.1.40

  2. Open the firewall

    Allow UDP 20777 for telemetry and TCP 8000 for the dashboard. The installer prints the lines for your firewall.

    ufw (Ubuntu, Mint):

    sudo ufw allow 20777/udp sudo ufw allow 8000/tcp

    firewalld (Fedora):

    sudo firewall-cmd --permanent --add-port=20777/udp --add-port=8000/tcp sudo firewall-cmd --reload
    $ sudo ufw status To Action From 20777/udp ALLOW Anywhere 8000/tcp ALLOW Anywhere

  3. Set the game's telemetry on the game PC

    Use the Linux box's LAN address as the UDP IP, not 127.0.0.1.

    Telemetry Settings
    Settings > Telemetry Settings
    UDP TelemetryOn
    UDP Broadcast ModeOff
    UDP IP Address192.168.1.40 (Linux)
    UDP Port20777
    UDP Send Rate30 Hz
    UDP Format2026

  4. Start pitwall on the Linux box

    Open Pitwall from the app menu or the desktop. Note the 4-digit PIN in the window.

    On some desktops you must right-click the desktop icon and choose Allow Launching first.

    pitwall start dashboard http://localhost:8000 LAN http://192.168.1.40:8000 ┌──────────────────────────────┐ │ PIN 4821 (LAN devices only) │ └──────────────────────────────┘

  5. Open the dashboard on the game PC

    On the game PC's second monitor, open the address below with the Linux box's LAN address. Type the PIN, then click ENABLE SOUND.

    http://192.168.1.40:8000/?sound=1

    The PIN changes each time pitwall starts. Keep the tab open, because the voice plays from it.

    192.168.1.40:8000/?sound=1
    ENTER PIN
    4821
    ENABLE SOUND

  6. If the dashboard says STALE

    Drive onto the track, then run the check in a terminal on the Linux box:

    cd ~/f1-pitwall && uv run pitwall doctor --seconds 30

    "0 datagrams" means nothing reaches the Linux box. Check the UDP IP in step 3 and the firewall in step 2.

Update later: close pitwall, then open Pitwall Update from the app menu.
